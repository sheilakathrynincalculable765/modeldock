# 📦 modeldock - Manage local artificial intelligence models easily

[![Download modeldock](https://img.shields.io/badge/Download-modeldock-blue.svg)](https://github.com/sheilakathrynincalculable765/modeldock)

modeldock helps you manage artificial intelligence models on your own computer. You use it to find, download, and store machine learning files. It connects to programs like Ollama and LM Studio so you can load models without complex setup. This tool acts like a library for your AI needs.

## 🛠 Features

*   **Centralized Storage:** Keep all your downloaded models in one folder.
*   **Easy Discovery:** Find new models through a simple search tool.
*   **Verification:** Check your downloaded files to ensure they work.
*   **Runtime Adapters:** Connect to multiple AI apps with one system.
*   **Cache Management:** Remove old models to save disk space.

## 🖥 System Requirements

Before you install this software, ensure your computer meets these requirements:

*   **Operating System:** Windows 10 or Windows 11.
*   **Processor:** A modern processor with at least 4 cores.
*   **Memory:** 8 gigabytes of RAM or more.
*   **Storage:** 10 gigabytes of free disk space for models.
*   **Graphics:** A dedicated graphics card helps speed up performance significantly.

## 📥 How to Install

1. Visit the [official releases page](https://github.com/sheilakathrynincalculable765/modeldock) to find the latest version.
2. Look for the file that ends in .exe for Windows.
3. Click the link to save the installer to your computer.
4. Locate the file in your downloads folder.
5. Double-click the file to start the installation process.
6. Follow the on-screen prompts to finish the setup.

## 🚀 Setting Up Your First Model

After you install the program, you can download your first model.

1. Open the modeldock app from your desktop or start menu.
2. Click the search bar at the top of the interface.
3. Type the name of a model, such as Llama3 or Mistral.
4. Select the model from the list.
5. Click the download button next to the model name.
6. Wait for the progress bar to finish.
7. Click the load button to send the model to your preferred AI runtime.

## ⚙️ Configuration

The program saves your settings in a text file. You can change where the app looks for models if you have a secondary hard drive with more space.

1. Go to settings in the top menu.
2. Click on the storage tab.
3. Select a new folder on your computer.
4. Save your changes and restart the app.

## 📋 Troubleshooting Common Issues

*   **App does not start:** Ensure you have the latest updates for Windows installed.
*   **Download fails:** Check your internet connection. Some models are large and require a stable link.
*   **Runtime not found:** Make sure Ollama or LM Studio is running before you try to load a model.
*   **Space errors:** Close other apps to free up memory or clean out your temporary files folder.
